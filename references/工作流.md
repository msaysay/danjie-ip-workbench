# 学员自己的内容流程

已有作业先读已有；缺哪项补哪项，不要求12项全部重做。

| 场景 | 原版方法 | 产物和衔接 |
|---|---|---|
| 说清服务谁 | 01 六维目标客群 | 原版HTML/JSON/长图；需求和顾虑保留来源与未知 |
| 说清我是谁 | 08 六维人设、09 四行简介 | 人设与简介；不把客户愿望当本人业绩 |
| 找客户关心的题 | 02 三圈选题 | 8方向、16处境、24情境，按实际模块逐组生成 |
| 开头怎么说 | 03 当头一棒、07 开场八式 | 三类反转或八式，选题和原句保留 |
| 怎么支撑观点 | 04 以理服人 | 有事、有数、有对比、有研究；没有材料只给取材方向 |
| 凭什么信我 | 05 亮出绝活 | 身份、对象/问题、规模、结果；没提供的成绩不编 |
| 最后让观众做什么 | 06 指条明路 | 给入口、留动作、总结、记忆、接问题，选一个落点 |
| 怎么连到更广话题 | 10 乾坤大挪移 | 客户—相关人—公共话题，嘴替和同题七法 |
| 我的真实经历 | 11 六脉神剑 | 六种访谈提纲与长图，不是六个虚构故事 |
| 同题多角度 | 12 一题多讲 | 6×6×6候选；组合是候选问题，不是已验证事实 |

模块的实际文件名与版本见assets/workbench/danjie-routes-v041.json；对应编号目录里只有一个SKILL.md。先读该原版要求，不自行替换成通用营销框架。原版13总装作为原始参考一并保留在assets/frameworks.zip的reference目录，不强迫先跑13才能使用网页版。

“聊天讲清楚，卡片选择与查看，脚本页改成愿意讲的话”。生成后先核对事实和公开范围，再自行决定是否准备拍摄。脚本确认后，可以在选题脚本页交给本机 StoryCue 做访谈，也可以下载脚本兜底。访谈问答回到这一题。工作台不剪视频，也不接 sayFrame。成片在外部剪好后，到发布页上传。
