# 需要连接时再安装

核心方法页、业务资料、选题脚本与本地保存不需要额外API。新内容由WorkBuddy当前登录的模型生成后接回；离线安装完成不等于离线AI生成。

- 灵感：学员在设置中自行注册、填写自己的TikHub密钥，按关键词、账号、热点选择平台。原设定的公开注册链接保留：https://user.tikhub.io/register?ref=u58I2I4n 。查询可能消耗本人的TikHub额度，不自动充值。
- 发布：AI用本包便携Python执行`scripts/install_optional.py publish`，联网安装独立发布环境和浏览器。需要FFmpeg/ffprobe时由WorkBuddy检查本机并通过官方发行渠道安装；不要把老师机器上的可执行文件、Cookie或配置复制过来。本人扫码登录自己的抖音/视频号等，先准备发布信息、核对视频理解/标题/封面/精确排期，再由本人决定发布。
- 抖音复盘：执行`scripts/install_optional.py analytics`，安装独立开源数据模块和浏览器。阅读随包上游PLATFORM_COMPLIANCE.md；登录/平台校验由本人完成。Mac默认用独立Chromium；Windows数据模块可能要求Edge，按实际检测结果处理，不假称两个系统都已登录验证。
- 视频号复盘：复用本人的发布账号与可见后台，不带老师历史记录。至少24小时再分析，累计和每日新增分开，不把播放量当成交或自动加投。
- 视频转文本：可执行`scripts/install_optional.py transcribe`，首次联网下载Whisper模型及依赖；本机还需要FFmpeg。优先读学员已有转写，不能拿文件名猜视频内容。Mac Intel/Apple Silicon的可用依赖以安装回执为准。

这些属于可选联网扩展，体积较大的浏览器、转写模型不预装在核心离线包。第三方服务可能收费、改接口或要求验证码；只报告本机实际状态。电脑和本地服务关闭时，定时更新不会继续运行。
