# 需要连接时再安装

核心方法页、业务资料、选题脚本与本地保存不需要额外API。新内容由WorkBuddy当前登录的模型生成后接回；离线安装完成不等于离线AI生成。

- 灵感：学员在灵感页或设置里按连接、注册、粘贴密钥、测一下四步，使用自己的 TikHub。原设定的公开注册链接保留：https://user.tikhub.io/register?ref=u58I2I4n 。工作台只做选题灵感；同一个密钥也可以在 TikHub 官网和文档里直接调用。查询可能消耗本人的 TikHub 额度，不自动充值。小红书只作为灵感查询，不作为发布账号。
- 发布：AI用本包便携Python执行`scripts/install_optional.py publish`，联网安装独立发布环境和浏览器。发布器要求 Python 满足 social-auto-upload 的 `requires-python`（当前为 `>=3.10,<3.13`），并且该解释器自带 venv/ensurepip。脚本沿用已经符合要求的当前解释器，因此用启动脚本里的便携 Python 3.12 执行时，仍用这份解释器建环境，不会另找系统 Python；否则依次使用已解压的 `.runtime/python`、安装包中的 `assets/runtimes/<平台>.tar.gz`（清单只有 Windows 与 Mac），以及 PATH 上的 `python3.12` / `python3.11` / `python3.10`。都没有时直接失败并说明如何提供解释器，不会用 3.13 及以上的系统 Python 建环境。`/api/health` 的 `publisher` 只有在该虚拟环境里能导入已安装的 `social-auto-upload` 时才为 true；只存在 `.venv` 里的 python 不算已安装。需要FFmpeg/ffprobe时由WorkBuddy检查本机并通过官方发行渠道安装；不要把老师机器上的可执行文件、Cookie或配置复制过来。本人扫码登录自己的抖音/视频号，先准备发布信息、核对视频理解/标题/封面/精确排期，再由本人决定发布。小红书不在发布账号里。
- 发布器坏了怎么重装：如果 `assets/workbench/vendor/social-auto-upload/.venv` 还在，但里面没有 Python（`bin/python` 或 Windows 的 `Scripts/python.exe`），再执行一次 `python scripts/install_optional.py publish`。它会删掉这个坏环境再重建，需要联网，不会登录，也不会发布。`/api/health` 的 `publisher` 为 false 时，页面上以前的「已登录」不能打开扫码窗口。写稿用的 WorkBuddy 登录和这里的抖音、视频号扫码不是同一件事。抖音和视频号没有「仅我自己可见」，确认发布会按平台默认范围发出，课堂里不要用真实账号试。
- 抖音复盘：执行`scripts/install_optional.py analytics`，安装独立开源数据模块和浏览器。数据模块的 Python 用同一套选择，但必须满足 douyin-mcp 的 `requires-python`（当前为 `>=3.11`）。阅读随包上游PLATFORM_COMPLIANCE.md；登录/平台校验由本人完成。Mac默认用独立Chromium；Windows数据模块可能要求Edge，按实际检测结果处理，不假称两个系统都已登录验证。
- 视频号复盘：复用本人的发布账号与可见后台，不带老师历史记录。至少24小时再分析，累计和每日新增分开，不把播放量当成交或自动加投。
- 视频转文本：可执行`scripts/install_optional.py transcribe`，首次联网下载Whisper模型及依赖；本机还需要FFmpeg。优先读学员已有转写，不能拿文件名猜视频内容。Mac Intel/Apple Silicon的可用依赖以安装回执为准。

这些属于可选联网扩展，体积较大的浏览器、转写模型不预装在核心离线包。第三方服务可能收费、改接口或要求验证码；只报告本机实际状态。电脑和本地服务关闭时，定时更新不会继续运行。
