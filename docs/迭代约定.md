# 迭代约定

先改源码，再用独立虚构资料验证，不动任何既有业务数据库。新增功能说明输入、产物、本人核对点和失败时如何继续。

事实、候选与演练保持区分；付款、决策和使用角色分开。旧版本与修改意见保留，同题资料不可串到另一题。文件中的确认标记不能替本人确认选题、整稿、发布或投流。

前台用学员能理解的话。已有作业直接复用；没有做过的才按原版方法带着完成。网页不会直接调用WorkBuddy私有接口、聊天数据库或程序凭据；共享目录与回填记录应可检查。

学员发行包按白名单打包，不从使用后的工作目录整体压缩。Git忽略运行数据只是一道防线，推送前仍检查暂存文件和秘密。Mac验证与Windows验证分开记录，不能用静态检查替代实机。
